# Sistema de Testes para Exames Clínicos

## 📌 Sobre o Projeto
Este projeto foi desenvolvido para automatizar e testar a inserção de dados clínicos de pacientes em um sistema de exames laboratoriais. O código recebe informações como nome, idade, gênero, histórico clínico, sintomas e exames anteriores, garantindo a integridade dos dados.

## 🚀 Funcionalidades
- Registro de informações do paciente
- Inserção de dados do exame
- Validação de campos obrigatórios
- Testes de integridade e consistência dos dados

## 🔍 Exemplo de Entrada de Dados
```json
{
  "nome": "Julio Campos Machado",
  "idade": 50,
  "genero": "Masculino",

  "tipo_exame": "Citologia",
  "tipo_amostra": "Sangue",
  "historico_clinico": "Paciente com histórico de hipertensão leve, sem diabetes, sem alergias conhecidas.",
  "sintomas": ["Cansaço frequente", "Tontura ocasional", "Pequenos episódios de sangramento nasal"],
  "exames_anteriores": [
    "Hemograma completo (10/2024) – anemia leve detectada",

```
